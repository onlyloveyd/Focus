# Focus —— 点开分心应用之前，先说清楚原因

你大概也有这样的时刻：工作卡壳的瞬间，手比脑子快，点开了微信、浏览器或者 WPS，扫一眼——没有任何目的——又切回来。一次二十分钟的专注，就是这么碎掉的。

Focus 在你和这些"无意识点开"之间放了一道闸门：名单里的应用一旦被切到前台，屏幕会立刻暗下来，要求你先度过几秒冷静期、写下这次打开的具体目的，然后才放行。你随时可以打开任何应用——它从不禁人，只是要求每个行为带着意识。

## 安装

1. 在 [Releases 页面](https://github.com/onlyloveyd/Focus/releases) 下载最新的 `Focus.dmg`；
2. 双击打开，把 Focus 拖进 Applications 文件夹；
3. 首次双击被 macOS 拦下属于正常现象（未上架 App Store 的应用都会这样）：打开 **系统设置 → 隐私与安全性**，拉到底点「仍要打开」；
4. 建议顺手设为开机自启：**系统设置 → 通用 → 登录项与扩展 → 添加 Focus**，之后无需再管它。

启动后，屏幕右上角菜单栏会出现一个**靶心图标**——那就是 Focus 在守护了。

## 第一次使用

开箱即用：微信已在默认拦截名单里（其他应用可在设置中随时添加）。现在就点一下微信试试：

1. 全屏深色遮罩盖住屏幕，显示微信图标和"今天第 N 次想打开它"；
2. 冷静期 5 秒内，「继续打开」按钮是灰的——让冲动先飞一会儿；
3. 写下你具体要干什么（比如"回复张三的消息"，至少 4 个字），回车放行；
4. 或者点「算了，回去工作」——你会被直接送回刚才工作的应用。

说明理由后会获得默认 5 分钟的免拦期，这段时间内自由使用，不会反复打扰。

## 日常使用

点击菜单栏靶心图标：

| 菜单项 | 作用 |
|---|---|
| 拦截已启用 | 总开关 |
| 暂停拦截 30 分钟 | 午休、通勤时临时放风，到点自动恢复 |
| 文案风格 | 弹窗的语气：标准（教练）、凶狠（教官）、温柔治愈（慈悲的朋友），随时切换 |
| 拦截名单与设置 | 管理名单、调整参数 |
| 查看记录 | 看你和冲动交手的战绩 |

**名单管理**：设置窗口里点「+」可以从当前正在运行的应用里直接挑选（豆包、抖音桌面版……），也可以手动输入。

**三个参数的通俗含义**：

- 冷静期（默认 5 秒）：弹窗出现后，按钮要多久才会亮起；
- 放行时长（默认 5 分钟）：写完理由后，这个应用多久之内不再被打扰；
- 原因最少字数（默认 4 字）：防止随手乱敲一两个字糊弄自己。

**记录页**：每一次拦截都会留档——打开了几次、忍住了几次、每次的理由是什么。一周之后回看，你会第一次看清自己的冲动长什么样子。

## 常见问题

**弹得太频繁？** 把「放行时长」调大一些，比如 15 分钟。

**觉得它管得太松/太凶？** 换一套文案风格试试；心情好时选凶狠，疲惫时选温柔——允许自己每天需要不同的对待方式。

**我的数据会上传吗？** 不会。所有记录只保存在你自己的电脑上，没有任何联网上传。也请留意：这些"打开原因"是相当私密的自我对话，不要把整个应用目录放进云盘同步。

**我能绕过它吗？** 能（强退进程即可），这是刻意的设计——它是一份你和自己的协议，不是监狱。绕过的动作本身需要意识，协议到这里就算履行了。

**想了解每个设计背后的道理？** 读一读 [DESIGN.md](./DESIGN.md)，里面有这个应用完整的设计哲学。
