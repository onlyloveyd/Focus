Focus v0.1.2

## 新增

- **开机自动启动**：在「拦截名单与设置」或菜单栏快捷菜单中均可开关。勾选后重启电脑，Focus 自动在菜单栏守护（基于 macOS 系统登录项）。

## 修复

- 勾选开机自启时应用卡死数秒：登录项注册改在后台线程执行，界面即时响应；
- 在系统设置中手动增删登录项后，应用内开关与菜单勾选不同步：现在设置窗口获得焦点、应用被激活、菜单展开时，都会回读系统真实状态。

## 改进

- 打包加入 ad-hoc 签名，改善系统信任度与登录项注册的稳定性；
- 菜单栏三个入口（文案风格 / 拦截名单与设置 / 查看记录）统一配上单色小图标。

## 安装

下载 `Focus.dmg`，把 Focus 拖入 Applications 覆盖安装（名单与历史记录保留）。首次打开（未公证应用）：系统设置 → 隐私与安全性 → 点「仍要打开」，或终端执行 `xattr -d com.apple.quarantine /Applications/Focus.app`。装完建议顺手勾选「开机自动启动」。

系统要求：macOS 13+，Apple Silicon 与 Intel 通用。
