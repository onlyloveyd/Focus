Focus v0.1.1

## 变更

- 默认拦截名单只保留**微信**：开箱只拦真正的病灶，浏览器、办公软件不再误伤，其余应用可在「拦截名单与设置」中随时添加；
- README 重写为使用者视角：安装引导、首次体验、日常使用与常见问题；
- 应用图标与全屏遮罩渲染修复（遮罩内控件首次渲染时按深色主题取色）。

## 安装

1. 下载 `Focus.dmg`，把 Focus 拖入 Applications（覆盖旧版即可，名单与记录保留）；
2. 首次打开（⚠️ 未签名未公证）：系统设置 → 隐私与安全性 → 点「仍要打开」，或终端执行 `xattr -d com.apple.quarantine /Applications/Focus.app`；
3. 建议在 系统设置 → 通用 → 登录项 里添加开机启动。

系统要求：macOS 13+，Apple Silicon 与 Intel 通用。
