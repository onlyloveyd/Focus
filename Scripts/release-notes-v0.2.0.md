Focus v0.2.0 —— 闭环补全版

## 新增

- **拆闸门也要过闸**：关闭拦截、暂停 30 分钟、把应用移出名单，这些"解除武装"的操作现在会弹出和应用拦截同款的冷静弹窗——冷静期 + 写下原因 + 记入日志。三套文案（标准/凶狠/温柔治愈）齐备，凶狠版会问你："立规矩的是你，拆台的也是你。"重新开启、重新添加则永远畅通无阻。想拆但收手了？那会记一条绿色的"没拆成"，也算战绩。
- **原因与时长对账**：写下"回个消息"放行后，Focus 会记录你实际停留了多久。是 2 分钟办完事，还是 40 分钟没忍住刷起来——记录页里一目了然，借口式原因无处遁形。
- **趋势图**：记录页新增最近 14 天柱状图，每天的"打开了"（橙）与"忍住了"（绿）并排呈现，附总忍住率，可按应用筛选。

## 改进

- 记录页重构：按应用汇总与拦截明细改为原生表格（Table），新增按应用的忍住率列；
- 数据库自动迁移（新增停留时长列），历史记录完整保留。

## 修复

- 副标题"今天第 N 次"首次显示为"第 0 次"的计数偏差；
- 拆闸收手事件归组错误导致汇总表出现同名应用两行；
- `--test-overlay` 测试数据不再污染记录与统计。

## 安装

下载 `Focus.dmg`，把 Focus 拖入 Applications 覆盖安装（名单与历史记录保留）。首次打开（未公证应用）：系统设置 → 隐私与安全性 → 点「仍要打开」，或终端执行 `xattr -d com.apple.quarantine /Applications/Focus.app`。

系统要求：macOS 13+，Apple Silicon 与 Intel 通用。
